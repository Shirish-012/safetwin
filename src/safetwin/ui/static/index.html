      A random 256-bit key, the strongest choice. It is shown once: save the key file before you use it.

      Save this key now. Without it, files masked with it can't be read back, and masking again gives other values. Keep it in a password manager, not in a shared folder.

      Anyone who types the same passphrase gets the same key, on any computer, so it can be guessed if it is short or common: use four or more random words. A random key is stronger.

      What this key does

      The key itself is 256 random bits (or the result of your passphrase). It never masks anything directly: safetwin derives a separate key for each job with HKDF-SHA-256, so one use can't reveal another. Which algorithm a column gets is chosen per file and column on the Mask tab, not here: the same key serves them all.
